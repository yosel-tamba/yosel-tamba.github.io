Attendance System Dashboard
CodeIgniter Bootstrap Dashboard Management Reporting

This is a student attendance management website designed for use in various schools, and it does not have a specific name to allow for flexible implementation. The platform features attendance monitoring that can be performed by homeroom teachers, as well as student attendance input through student card tapping. Additionally, administrators have access to a dashboard for managing attendance records, homeroom teachers, and students. The application also includes a school information management feature, allowing each school to configure its own details and settings, making the attendance website highly flexible and adaptable for different educational institutions.

  • Role-based access for admins, and teachers.
  • Attendance input via student card tapping.
  • Dashboard for managing attendance, teachers, and students.
  • School information management for flexible implementation.

Sibi Learning App
Next.js Flask Machine Learning Education Practice

Sibi Learning App is an interactive web application that leverages deep learning to recognize and evaluate Indonesian Sign Language (SIBI) gestures in real time. The platform provides users with a practice mode where they can perform sign language gestures, and the system instantly scores their accuracy, offering immediate feedback for improvement. The application is built with a responsive Next.js interface, ensuring accessibility across both desktop and mobile devices, making it a versatile tool for learning and practicing SIBI.

  • Real-time hand gesture recognition via a Flask inference API.
  • Interactive practice mode with instant accuracy scoring.
  • Responsive Next.js interface for desktop and mobile.
  • Provide list of available sign language exercises.
  • progress tracking for users to monitor their improvement over time.
